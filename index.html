Pick a field to get started.
Modern item example: pick Item → Diamond Sword → Consumable → choose the food/drink behavior. CommandForge builds something like /give @s minecraft:diamond_sword[minecraft:consumable={consume_seconds:1.6,animation:'eat'}]. Item components replaced the old unstructured item tag field starting in Java 1.20.5; arbitrary custom data belongs in minecraft:custom_data.
